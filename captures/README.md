# Captures

Store the `.pcap` / `.pcapng` files for each case here (small files only, under
about 5 MB), named after the case: `01-port-scan.pcap`, `02-arp-spoofing.pcap`.

Before committing a capture, open it in Wireshark and confirm it contains only
lab traffic: no real passwords, tokens, personal data or other people's traffic.
